# acep-muchtarom13
Nama : Acep Muchtarom
NIM : C2583207034
Kelas : PTI3B
Program ini menggunakan struktur data array untuk menyimpan informasi nama produk, harga, jumlah stok, jumlah terjual, dan pendapatan. Terdapat sembilan fitur utama, yaitu melihat daftar produk, menambah dan mengubah produk, melakukan transaksi penjualan, menambah stok, mencari produk, mengurutkan produk, membuat laporan penjualan, serta memeriksa stok yang menipis. Program ini juga dilengkapi validasi input untuk mengurangi kesalahan pengguna. Secara keseluruhan, aplikasi bertujuan mempermudah pengelolaan persediaan barang dan pencatatan transaksi penjualan kantin secara terstruktur dan efisien
